# Gestión de Proyectos de Inteligencia Artificial
Código de las actividades que se realizarán durante el curso.

## Contenido
```
Actividad-04/ Identificar e implementar el modelo preentrenado más adecuado para un caso de uso específico.
```

Cada tema incluye su propio directorio `data/` con los datasets que usan los notebooks

## Requisitos

- Python 3.10 o superior
- `pip` actualizado
- ~3 GB libres en disco (los modelos de Hugging Face)
## Instalación

### Anaconda / Miniconda

1. Instala [Anaconda](https://www.anaconda.com/download) o [Miniconda](https://docs.conda.io/en/latest/miniconda.html).

2. Clona o abre el repositorio y abre una terminal en la carpeta elegida.

3. Crea el entorno conda con Python 3.10 y actívalo:

   ```bash
   conda create -n <<nombre>> python=3.10 -y
   conda activate <<nombre>>
   ```
Para salir del entorno cuando termines: `conda deactivate`.
