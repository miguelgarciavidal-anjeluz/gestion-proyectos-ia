# Dataset IBM AMLSim
IBM AMLSim: El proyecto AMLSim es un simulador basado en agentes múltiples diseñado para generar datos de transacciones bancarias sintéticas junto con un conjunto de patrones conocidos de lavado de dinero. Su objetivo principal es servir como herramienta para probar modelos de aprendizaje automático (machine learning) y algoritmos de grafos.

Este conjunto de datos es un ejemplo generado con IBM AMLSim.

Contenido
El repositorio/dataset incluye tres conjuntos de datos principales:

Conjunto de datos de cuentas (accounts): Contiene información detallada sobre todas las cuentas bancarias cuyas transacciones están bajo monitoreo.

Conjunto de datos de alertas (alerts): Contiene las transacciones que activaron una alerta conforme a las normativas y directrices de prevención de lavado de dinero (AML).

Conjunto de datos de transacciones (transactions): Contiene el registro completo de todas las transacciones, incluyendo información sobre las cuentas de origen (remitente) y destino (receptor).
